# HelloSwift

A starter Swift package: a small string library, a command-line tool and tests.

```sh
swift run                         # run with sample inputs
swift run HelloSwift "noon" "abc" # check your own strings
swift test                        # run the tests
```

- `Sources/StringTools/` – library code (`isPalindrome`, `wordFrequencies`)
- `Sources/HelloSwift/main.swift` – command-line entry point
- `Tests/StringToolsTests/` – tests written with Swift Testing
