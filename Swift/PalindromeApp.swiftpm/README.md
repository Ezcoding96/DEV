# PalindromeApp (iOS)

A SwiftUI iPhone/iPad app built on the `StringTools` library from `../HelloSwift`.
Type text and it shows live whether it's a palindrome, plus word counts.

## Run it in the Simulator

1. Install **Xcode** from the Mac App Store (the Command Line Tools alone can't run iOS apps).
2. Open Xcode once so it installs the iOS Simulator runtime.
3. Run `open PalindromeApp.swiftpm` (or double-click this folder in Finder).
4. In the toolbar, choose an iPhone simulator, e.g. "iPhone 17", then press ⌘R.

You can also see `ContentView` live in Xcode's canvas (⌥⌘↩) without launching the Simulator.
